01 / GET STARTED

先完成一次小练习

准备一段短音频和已有的 SRT / VTT 字幕。这个流程无需注册，也不必先配置 AI。

  1. 安装并打开客户端。从下载区选择设备对应的版本，安装后打开 Clarora。进入「音频管理」。
  2. 创建练习组，导入一段音频。点击「新建组」，确认名称；点击「导入音频」选择 MP3、M4A 或 WAV 等文件。练习组用于整理材料，不会改变原音频内容。
  3. 为这段音频配上字幕。选中音频，导入对应的英文 SRT / VTT。没有字幕时先直接听，稍后按字幕章节生成。
  4. 开始学习。进入「音频学习」，先听一遍，再点击听不懂的句子或单词定位播放。按需要降低倍速，开启「跟随」让字幕随播放位置移动。
  5. 留下一句，明天再听。开启「截取片段」，选出一句、调整 A/B 边界，保存为闪卡。在「闪卡复习」中再次听这段内容。

完成后：你会得到一个练习组、一段带字幕的音频和一张可复习的片段卡。之后再按需要添加 AI、写作或书库。

选择版本并安装

  1. 以下载页的发布状态为准。显示「待发布」时，查看构建说明或等待渠道开放；不要用其他平台或 RN 的包替代桌面主版本。

03 / SET UP AI

分清本地模型与远端 AI

已有资料的阅读、播放和复习可以离线使用。字幕转写可以选本地模型；聊天、中文翻译、写作批改和图片识字会调用你配置的模型服务。

配置聊天、翻译和批改

  1. 打开「设置 → AI 服务」。填写服务商提供的 Base URL、模型 ID 和 API Key。地址格式例如 https://api.example.com/v1，这是格式示例，需要替换为你的服务地址。
  2. 保存，再做一个短请求。点击「保存 AI 与学习设置」，打开「学习助手」提出一个简短问题。能收到完整回答后，再尝试长文批改或整组翻译。
  3. 按任务选择合适能力。图片识字需要视觉能力，可单独填写视觉模型。远端转写需要服务同时支持音频转写接口；只支持聊天的模型不能直接当作转写模型。

选用本地字幕模型

  1. 先下载，再选用。在「本地语音识别模型 · ASR」里下载模型。纯英文可先从较小的 Whisper .en 模型尝试；SenseVoice 面向多语言，实际效果取决于音频和模型。
  2. 切换本机转写并保存。将转写引擎设为 local，选用已下载模型，再点击保存。仅下载文件或点击选用而不保存，不代表配置已生效。
  3. 用短音频验证。生成一小段字幕，确认文字和时间轴。完整分发包会包含相应辅助程序；自行构建缺少 FFmpeg 或推理运行库时，可在「运行环境」查看具体缺项。

网络与密钥：选择本地转写时，转写本身不上传音频；远端转写、翻译和 AI 问答会发送相应材料。较新桌面构建的密钥默认保存在本机数据库，可在「密钥存储」开启系统凭证库保护；不同版本与 RN 的方式可能不同。应用导出的资料备份不包含这些密钥，换机后需单独配置。

04 / AUDIO STUDY

把一段音频听成自己的材料

音频是最容易开始的练习：不必等视频下载，也不要求一次听懂全部。先整理出一段带字幕的材料，再用「整段—单句—片段」三种粒度反复听，最后把值得记住的句子留下来。

准备：先建组，再让字幕对上

  1. 按用途建练习组。在「音频管理」新建或选择练习组。可以按课程、日期、考试或主题分类；一个组最好只放同一类材料，之后整组生成字幕和连续播放才不会混在一起。
  2. 导入音频并核对名称。点击「导入音频」选择 MP3、M4A、WAV 等文件。列表支持名称搜索和「全部／附字幕／待配字幕」筛选；双击音频名称可原位改名，按 Enter 保存，Esc 取消。
  3. 配上对应字幕。选中音频，从「查看／管理字幕」进入学习页，导入 SRT／VTT，或按字幕章节生成英文。导入后先试听开头和结尾，确认字幕确实属于这份音频。
  4. 先听一遍，再决定怎么练。进入「音频学习」，先完整听一遍了解内容。之后按下面的方式调整倍速、循环和字幕显示，而不是一上来就逐句抠细节。

精听：用不同粒度控制难度

遇到不同的听力问题，换一种播放方式
你现在的问题建议操作结果
语速太快打开底部倍速菜单，先从 0.75× 开始，听顺后再逐档回到原速。降低语速不改变音高，适合先建立句子轮廓。
一句总听不全点击该句字幕定位，再在播放模式菜单选择「单句循环」。只重复当前句，听清后再手动换句。
需要自动推进选择「每句三遍」。当前句播放三次后自动进入下一条有效字幕，最后一句完成后暂停。不用反复点播放，适合通篇跟听。
只想练一个片段在播放模式或设置中开启 A–B，标记起点和终点；B 必须晚于 A。在范围内循环，进度条会显示范围和边界。
总想看字幕在页面顶部切换到「盲听」，右键字幕行或点「查看」临时揭开。先靠耳朵抓意思，核对后再继续播放。

「跟随」开启时，当前播放句会自动滚到列表中间；想自己翻看时可以先关掉。点击字幕单词或句子仍用于定位播放；开启「截取片段」后，点击和 Shift 点击才改为设置片段边界。

留下：从听到复习

  1. 截出一句真正有用的内容。开启「截取片段」，点击单词设置 A 点，Shift 点击扩展，再拖动波形边界微调。字幕里的 A/B 竖线也可以直接拖动，边界会随字符位置变化；确认后保存为闪卡，卡片会记住来源和时间范围。
  2. 在字幕里找回已收藏的句子。已保存的片段会在字幕中显示绿色下划线。左键仍用于定位播放；右键下划线可以查看对应卡片，或取消收藏复习。取消只移除闪卡和复习记录，媒体与字幕仍在。
  3. 第二天先听后看。到「闪卡复习」选择音频片段卡，先听再揭示文字。按真实掌握程度评分，下一次复习时间会跟着变化。
  4. 把听过的句型再用出去。打开「句型搜索」，输入 When、Why did 等句首，从所有音频和已下载视频字幕里找原句。可以只试听某一条，也可以从第一条连续听下去。

新版功能 整组字幕与后台任务

在音频管理或学习页的当前组标题下，可以「整组生成英文字幕」或「整组翻译中文字幕」。生成英文会跳过已有有效字幕；翻译只发送缺少中文的句子，没有英文的音频会先转写。单条失败会继续处理其他音频，取消后已完成的结果保留。

字幕任务在后台运行，期间可以切换音频、练习组或其他栏目。顶部任务卡会显示最初的音频或组名与进度，完成只保存对应材料，不会把你切回旧音频。重新生成会替换当前音频的旧字幕和时间轴，操作前先确认材料选对了。

整理与批量导入

「多选」可以全选当前筛选结果、移动到其他组、合并为学习版或移除记录。合并会按当前列表顺序衔接音频和双语字幕，原始记录与文件保留；学习页默认使用合并版，避免同一材料重复出现。

需要批量导入时，先用主窗口右上角「悬浮窗」确认当前练习组，再点击导入执行设置中保存的命令。命令每行输出一个本机音频文件的完整路径，导入固定到点击时的组；完成后可以直接在悬浮窗里逐条命名。选择口语分组时，返回的音频会在该组新建口语题目。

需要把文字变成听力材料时，使用「文字转音频 · Kokoro ONNX」：下载模型后填写文本、选择音色和语速，生成会保存为音频并带逐句时间轴。首次下载需要联网，生成和后续播放在本机完成；正文不会发送到远端。

常见误区：「逐句重复」只是按现有字幕起止时间重播，不会自动修正字幕。开头或结尾总被截断时，先试听原片确认，再保留旧字幕后重新生成当前音频的字幕。A–B 工具适合临时微调一个片段，不等于编辑整份字幕时间轴。

05 / SUBTITLES

先得到英文，再添加中文

  1. 已有字幕就直接导入。选择对应音频，导入 SRT / VTT；TXT 可按行估算时间轴，精听时优先使用真实带时间戳的字幕。
  2. 没有字幕时生成英文。保存好转写设置，在音频学习工具栏或音频管理中点击「生成字幕」。等待处理结束，再检查实际内容。
  3. 再翻译成中文。点击「翻译成中文」，使用聊天 AI 生成双语字幕。它保留英文和时间轴，不需要重新识别音频；翻译需要可用的 AI 服务。
  4. 检查时间边界。听一句开头和结尾，确认没有提前停止或混入下一句。生成结果可能识别错误；旧字幕时间轴不准时，可先保留原文件，再重新生成当前材料并翻译。
一个最小 SRT 示例
1
00:00:00,000 --> 00:00:03,000
I learn a little every day.

2
00:00:03,000 --> 00:00:06,000
Small steps make a difference.

把示例保存为 UTF-8 编码的 lesson.srt 即可用于熟悉导入流程。示例时间不对应你的真实录音，需要用实际材料的字幕替换。

新版功能 整组音频处理

在「音频管理」选择目标组，点击整组生成英文或整组翻译中文。程序按组处理，跳过已有结果；部分中文缺失时按需补齐。发生错误会继续处理其他音频，并汇总失败项。取消后已经完成的结果会保留。

这与视频的「全部P翻译中文」规则不同：视频只要某个 P 任一句已有中文，就跳过整个 P，避免覆盖已有翻译。

06 / VIDEO STUDY

一句一句听懂视频

视频比音频多了来源、分 P 和画面，但精听方法相同：先把要学的这一集准备好，再让字幕带着你走。不要一边找资源一边学，先完成准备，再进入播放。

准备：先选来源，再选这一集

两种视频来源的差别
来源导入方式需要注意
本地视频在「视频学习 → 我的视频」选择本机文件，可一次选择多个。文件移动或删除后需要重新定位；本机 ZIP 备份会保留可用的原文件。
bilibili在「更多」中填写 BV 号、av 号或完整链接；有 ?p= 时直接导入指定集。下载受网络和来源可用性影响。云备份只保存来源链接与字幕，恢复后需要重新下载原片。
  1. 把视频收藏起来。导入后会进入「我的视频」，显示来源、总 P 数和已下载数量。重复导入同一文件会去重，同名但路径不同的文件会分别保留。
  2. 选对 P 再准备媒体。多 P 视频在标题栏 P 数或右侧「选集」切换。每个 P 的字幕和时间轴分别保存，不要把同一篇文稿套到另一个 P。
  3. 需要连续看时打开自动下一 P。当前集真正播放结束后，已下载的下一集会直接播放，未下载的会先下载；最后一集播完停止。单集循环或 A–B 循环优先，此时不会自动换集。

字幕：先有英文，再补中文

按范围选择处理方式
范围操作行为
当前 P字幕区「生成字幕／重新生成」，或从「更多 → 导入英文字幕」加载 SRT／VTT。重新生成会替换当前 P 的旧字幕与时间轴。
当前 P 的中文点「翻译中文」。保留英文和时间轴，只补缺失中文；已有中文不会重复发送。
整个选集「选集」或字幕「更多」里的「生成英文字幕」。按顺序处理所有 P；已有有效字幕跳过，未下载的先下载再转写。
全部 P 的中文「全部P翻译中文」。只要某个 P 已有一句中文，就跳过整个 P；缺英文的 P 会列出原因，不会为翻译自动下载或转写。

字幕任务会显示提取音轨、语音识别、保存字幕等实际阶段；取消后已保存的结果保留。整个选集的生成任务在后台执行，期间可以切到其他 P 或其他收藏，任务卡会显示处理到哪一集。

精听：把播放器当作句子工具

视频页最常用的精听操作

反复听一句点字幕行或控制栏进入「单句循环」。播放器只重复当前句，手动换句或停止后退出。

三遍模式进行中会显示当前是第几遍；等待字幕或本句完成时也会显示对应状态。点击音轨会在当前重复句内定位，超出范围时停靠到最近边界，不会悄悄切换句子。要换句，用左右键或直接点击目标字幕。

输出：文稿、复制和提问

  1. 用英文文稿通读。右侧「英文文稿」显示当前视频或当前 P 的纯英文转录，带句数和约词数，可独立滚动。
  2. 只复制需要的内容。每句右侧「复制」复制完整正文；「更多 → 复制双语字幕」按顺序复制全部文字，不含时间戳；「复制英文全文」只复制英文，不含中文。
  3. 带着引用提问。点「问当前句」「问整段字幕」或某条字幕的「问 AI」，引用会先放进右侧学习助手。确认原文后再输入问题，切换视频不会替换已添加的引用。
  4. 导出字幕留档。「更多 → 导出 SRT」保存完整字幕文件；这条路径不改变播放状态，也不会重新转写。

新版功能 离开再回来，继续原来的位置

切到其他栏目时视频会暂停并保存最新进度。返回「视频学习」后停在离开的位置，点击播放继续；从音频或复习模块打开同一视频的片段，返回时仍恢复完整视频的学习位置。手动跳转、换视频或离开模块会结束旧的逐句重复模式。

视频页收起学习助手、关闭菜单或点击播放控件后，键盘会交回视频：左右键切句、空格播放／暂停。正在编辑问题或使用输入法时，按键仍用于输入。

导入失败先查来源，不要先怪字幕：确认链接正确、网络能访问来源、该 P 仍可观看。已恢复的来源记录只表示收藏还在，不代表视频文件已经下载。缺媒体时先按提示准备对应 P，不要用另一 P 的字幕掩盖问题。

07 / REVIEW

把值得记住的内容留下

  1. 导入自己的词卡。在「闪卡复习」的学习选项中选择文本或 Anki 导入。先用几张卡确认格式，再导入大量内容；RN 移动端的导入能力请查看平台说明。
  2. 选择复习方式和类型。计划复习优先安排到期卡，并受每日新卡额度限制；自主复习按你选择的内容练习。可按单词、句子、AI 问答或片段筛选。
  3. 先回忆，再评分。查看答案后按真实掌握程度选择评分，它会影响下一次复习时间。音频片段卡可先听再揭示文字。
  4. 从精听中制作片段。在音频学习开启「截取片段」，点击单词确定范围，Shift 点击扩展，拖动波形上的左右边界试听；保存为闪卡。视频使用 A/B 范围保存片段。
文本词卡格式示例
clear - 清晰的
focus - 专注
review - 复习

一行一张词卡；也可用 Tab 等支持的分隔符。导入目录的替换行为与普通追加导入不同，使用前确认界面的范围说明并保留备份。

新版功能 已收藏的片段会在字幕中以下划线标出。左键仍用于定位或选段，右键已收藏部分打开取消收藏复习入口；取消会移出对应闪卡复习，保留媒体和字幕。AI 重点下划线与片段收藏是不同标记。

08 / WRITING

从题目到修改，完成一篇

写作不是「写完等分数」，而是一个可以重复的闭环：读清题目、写下初稿、拿到具体意见、改出下一版。Clarora 把每一版都留在本机，方便你对照自己的变化。

建立自己的写作库

  1. 先建组，再新建写作。进入「写作练习」，在「我的写作」切换分组或新建组。新组默认使用当天日期，也可以改成考试、话题或课程名称；选定分组后新建的写作会归入该组。
  2. 给每篇一个能找回的标题。标题可选，但建议写上考试、主题或日期。已保存的写作可以在编辑区「移动分组」，不必删除重写。
  3. 用标签做跨组筛选。在「题目标签」输入名称，按 Enter 或点「添加标签」；点标签上的「×」移除。标签只用于分类，随草稿自动保存并纳入备份。

把题目和自己的作答分开

  1. 完整粘贴题目。在「写作题目」放入题目、任务要求和评分标准。从网页复制带格式的内容时，会保留标题、段落、列表、换行、粗体和斜体，并显示格式预览；点「编辑题目」可以改 Markdown 正文，再点「预览格式」核对。
  2. 设定本次字数目标。可以在草稿标题旁填写目标词数，留空表示不设目标。字数统计会显示当前进度和还差多少词，写作时不用自己反复数。
  3. 在「我的作答」里写初稿。题目和作答是两个独立编辑器，正文 24px，支持回车换段、自动折行和内部滚动；窄窗口自动上下排列。停止输入后自动保存，也可以手动点「保存写作」。
  4. 切换前不用怕丢。切换篇目、分组或模块前会保存当前草稿，重启后继续编辑。空白新稿不占用列表；保存失败时保留编辑内容并显示错误，不会悄悄清空。

选择适合这一稿的批改方式

两种批改不是二选一，可以先用一种再用另一种
方式适合什么时候用你会看到什么
综合批改刚写完初稿，想知道整体是否切题、结构是否站得住。切题、结构、语法用词、修改建议和参考润色稿。设置目标词数时，不足会先说明差多少，并指出可在哪些段落补原因、例子、细节、对比或结果。
逐处修改整体方向已经确定，想逐句看哪里可以改得更准确。在提交原文中用删除线和下划线标出变化，批注按编号查看，另有完整建议稿预览。

提交前会先保存草稿，再把当次题目和作答一起发送到设置中的聊天模型。批改可以取消，切到其他模块后也会继续；失败、截断或取消不会新增一条成功批改。

把反馈变成下一版

  1. 先判断，再改。对照题目检查是否回答了任务，再处理结构和句子。不要直接把参考润色稿当成自己的最终稿；先用自己的话重写，再比较差别。
  2. 在「原稿」里继续修改。每次成功批改都会单独保留，并保存当次题目和作答的快照。点「查看批改结果」打开历史意见，展开「查看本次提交原文」可以核对当时到底交了什么。
  3. 带着上下文追问。在任一批改结果里点「追问 AI」，助手会预览这次提交的题目、作答和批改意见；设置过目标词数时，还会带上目标、实际词数和差额。确认引用后再问「这一段为什么不够具体」之类的问题。
  4. 隔一段时间重写一次。同一道题可以新建另一篇写作，不看旧稿先写，再对照两次的批改记录。提升往往来自第二次独立作答，而不是只把旧稿改到满分。

新版功能 边看意见边改原文

宽窗口中可以把作答草稿与批改历史左右并排，长批改独立滚动；全屏等宽窗口会给草稿更多宽度并同步加高编辑框，窄窗口改为上下排列。批改中的 Markdown 表格会按可用宽度换行，不再被横向截断。

删除写作需要再次确认，并会一并删除它的批改历史。删除前确认这篇已经导出备份，或确实不再需要。

关于评分与隐私：除非你在题目中提供了明确的评分标准，AI 反馈不应被当成正式考试分数。提交批改会把题目和作答发送到你配置的模型服务；写作草稿与批改历史会进入本机 ZIP／云备份，但 AI 密钥不包含在备份里。题目和作答分别有长度上限，超出时界面会提示，不会悄悄截断正文。

09 / READING

阅读 PDF 与电子书

  1. 导入书籍。进入「文档阅读」，选择 PDF、EPUB 或 TXT。桌面主版本支持这三种格式；RN 的文档阅读以对应版本的 PDF 能力为准。
  2. 用目录和页码定位。打开书库中的材料，通过目录、上一页／下一页或页码导航阅读；PDF 可调整缩放，电子书按章节和内容分页展示。
  3. 围绕当前材料提问。打开学习助手，先确认引用的是正确书籍或页面，再问词义、段落结构或内容理解。扫描型 PDF 的页面图像识字需要视觉模型和网络服务。
  4. 继续阅读并备份。客户端保存阅读进度；换机前导出含附件的资料备份，再在目标设备导入。只复制数据库而不复制书籍文件，不能保证重新打开材料。

EPUB 与 PDF 的分页方式不同，页码可能不对应纸质书。带加密保护或其他格式的书籍不能保证直接打开；遇到格式错误，先确认文件完整且属于支持的类型。

10 / SPEAKING

用题库把口语练成日常

口语练习不只是按下录音键。先有一道值得回答的题，再准备参考表达、写下自己的答案，最后录下来对照。Clarora 把题库、草稿和跟读记录放在同一页，方便你反复练同一道题。

建立口语题库

  1. 按场景建组。进入「口语练习」，在页面顶部的题库卡片新建或选择分组。可以按考试、话题或课程分类；分组可以添加标签，点标签旁的「×」移除，标签随分组备份。
  2. 每道题以音频为来源。新建题目时选择一段音频。题目卡片会显示波形、播放时间和倍速；点击波形可定位，暂停后能从当前位置继续。移除音频后仍可查看已保存的文字，也可以重新添加音频。
  3. 批量准备题目。「命令批量导入」会在当前组为每个音频新建一道题，「命令导入本题」用于单条补充。两者共用「设置 → 悬浮窗与命令导入」里的本机命令，不依赖 AI 配置。
  4. 先把题目听懂。点「音频转文字」生成原文，「翻译成中文」补译文；两者都会自动保存。已转写的音频还能用「AI 生成标签」归纳主题，未转写的会跳过。

准备参考表达，而不是背标准答案

  1. 写自己的作答草稿。每道题都有独立草稿。可以直接编辑、粘贴，或导入 UTF-8 的 .txt／.md 文件；导入会追加到已有草稿末尾。
  2. 设置目标词数。在草稿标题旁填写目标词数，留空表示不设目标。字数统计会显示当前进度和还差多少词，停止输入后自动保存。
  3. 先听一遍再开口。点「生成读音」用本机 Kokoro 把草稿读出来，再点一次可暂停或继续。它使用音频页选择的音色和语速，需先下载模型；生成结果按草稿和音色缓存，正文不发送到远端。
  4. 整组一起批改。当前组至少有 2 道题写了草稿时，点「整组批改」，会把题目和作答一起加入学习助手引用，并预填检查前后答案重复的要求。单题也可以点「AI 批改」，选择综合批改或逐处修改。

录音跟读与复盘

  1. 先听参考，再录自己。播放题目音频或生成的读音，跟读几遍后再使用下方独立的录音入口。第一次录音前按系统提示授予麦克风权限。
  2. 转写并对照。停止录音后使用已保存的转写设置识别，查看参考文本和识别文本的差异。
  3. 按维度改，而不是只盯总分。对齐结果会指出漏读、读错、多读、完整度和语速。先处理漏掉或读错的词，再调整停顿和速度；重录同一句，比较这次的变化。
  4. 把好用的表达留下来。把值得复用的句子保存为闪卡，或把音频片段加入复习。第二天先听再复述，比只看文字更接近真实开口。

2 分钟听题目音频，确认这道题在问什么，必要时看译文。能用自己的话复述题目要求。

新版功能 题库与题目的完整备份

口语分组、题目、题目音频、作答草稿、目标词数和批改历史都会纳入资料备份；原始跟读录音不包含在备份里。换设备前先导出本机 ZIP 或完成云备份，恢复后核对题目音频是否可读。

分数说明：口语分数表示识别文本与参考句的对齐程度，包含漏读、读错、多读、完整度和语速，并不是声学发音或音素评测。录音依赖麦克风权限和系统输入设备；没有声音时先检查这两项，再重录。AI 批改和翻译会把对应文字发送到你配置的模型服务。

顺带：拍照识字

进入「拍照识字」，选择需要识别的图片；支持拍照的设备可从相应入口拍摄。先配置可用的视觉模型，识别结果可以复制，或交给学习助手继续提问。远端视觉识别会发送图片，不属于本地字幕模型的离线能力；扫描型 PDF 的页面识字也走同一条视觉模型路径。

11 / FOCUS

让一次练习有开始和结束

  1. 选择时长并开始。使用全局「专注时间」条的「专注时长」选项，或进入「冥想专注」。同一轮计时在模块间共用。
  2. 按需要暂停或继续。切换学习栏目不必重新开一轮；临时离开可暂停。重置会改变当前轮次，不是普通继续。
  3. 注意阶段变化。专注完成后进入休息，再按当前设置继续。若没有提示音，检查应用音量、系统输出设备和版本是否包含相应提示音实现。

新版功能 新构建会保存运行中的截止时间或暂停剩余时间，退出后重开按实际经过时间恢复。关闭期间已经到期时只结算上一轮，并停在下一阶段等待继续，不自动累计离线多轮。早期没有保存的计时无法事后找回。

12 / KEEP YOUR LIBRARY

备份资料，再安心换设备

先做一份本机 ZIP 备份

  1. 打开设置中的备份入口。选择导出本机资料，保存 ZIP 到你方便管理的位置。完整备份包含学习记录和对应附件，不只是一个数据库文件。
  2. 在目标设备导入。打开 Clarora 的导入／恢复入口，选择备份文件，等待合并结束。先核对词卡、音频、书籍和阅读位置，再删除旧设备上的资料。
  3. 从 RN 迁移时选对入口。桌面主版本可导入 RN 数据库快照；两版资料目录独立。涉及音频或书籍时需保证原附件可读，迁移前保留两端备份。

使用自己的对象存储换机

  1. 保存存储配置。填写 S3 兼容存储或阿里云 OSS 的 Endpoint、Bucket、区域／前缀和所需密钥。具体字段以所选服务与客户端表单为准。
  2. 先上传一个备份版本。点击云备份入口，等待上传完成。只保存存储配置不会自动上传或自动同步资料。
  3. 另一端读取并合并。配置相同存储位置和前缀，读取版本列表，选择需要的版本合并到本机；不要把“没有读取到版本”当成可以删除旧资料。

这是手动版本备份与合并。不是自动实时双向同步，也不会自动传播删除。本机已有内容优先，复习进度按相应较晚评分合并。应用备份不包含 API / 存储密钥，目标设备要重新配置；HTTPS 传输也不等于端到端加密。

新版功能 新构建的云备份对 B 站原片保存来源链接、字幕及学习记录，恢复后按需重新下载；自己导入的本地视频仍按附件备份。本机 ZIP 会保留可用的视频原文件。来源下架或失效时，链接不保证仍可下载。

13 / TROUBLESHOOTING

遇到问题，从这里排查

更新后界面还是旧的，或找不到教程中的按钮

先退出所有旧实例，再从刚安装的位置打开 Clarora，确认 Dock／任务栏没有仍固定旧包。RN 和桌面主版本的界面不同；「新版功能」也不一定在早期 v0.2.2 中。回到下载区核对版本和发行说明。普通安装包更新后无需自己重新编译。

字幕重复播放时，开头或结尾被截断

逐句重复使用字幕已有的起止时间。先试听原片的对应位置，保留旧字幕后对当前音频或 P 重新生成，再按需要翻译中文。A/B 工具可用于微调本次片段范围，但不等于编辑整份字幕时间轴；不要把反复重播当作已经校准字幕。

英文字幕能生成，中文翻译却失败

英文可能走本地转写，中文翻译则使用聊天服务。检查是否已保存 Base URL、模型 ID 和 API Key，先用学习助手完成一次短问答，再重试翻译。不要只重新下载字幕模型。

AI 返回 401、404 或 429

401 通常与密钥或授权有关；404 检查地址、模型 ID 和接口是否支持；429 查看服务商的限流或额度提示。以实际错误内容为准，避免反复提交长音频。Base URL 不是服务商控制台的网页地址。

模型已经下载，仍提示无法转写

确认模型已选用并保存、转写引擎是 local，且模型文件完整。打开「运行环境」检查 FFmpeg 和推理辅助程序；下载模型不会自动安装自行构建所缺的原生运行库。先使用短音频复验。

音频、视频或计时没有声音

依次检查客户端是否暂停／静音、音量、系统输出设备和耳机连接。换一个已知能正常播放的文件再试。录音问题还需检查麦克风权限和输入设备；计时提示音与学习媒体属于不同播放路径。

B 站视频导入失败或某个 P 无法播放

检查链接是否正确、当前网络能否访问来源，以及该 P 是否仍可观看。已恢复的来源记录不表示视频文件已经下载；选择对应 P 按提示准备媒体。查看客户端任务错误，不要用另一 P 的字幕掩盖缺失媒体。

换设备后看不到资料或云端版本

确认旧设备已完成一次备份，新设备使用相同 Endpoint、Bucket 和前缀，读取版本后执行合并。两版客户端并不共用同一资料目录。保留旧库和备份，先核对附件路径与读取权限；仅配置云存储不会自动下载资料。

哪些操作会联网，资料会发到哪里

本地阅读、复习、播放以及配置正确的本地转写／语音合成可离线运行。模型下载、B 站导入和云备份需要联网；远端转写会发送音频，翻译／问答／写作批改会发送引用文本，图片识字会发送图片至你选择的服务。官网教程不读取或上传这些资料。

仍有问题时，可在GitHub Issues ↗说明客户端版本、系统、操作步骤和错误信息。截图或日志中请去掉密钥与不希望公开的学习资料。
