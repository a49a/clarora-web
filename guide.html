01 / GET STARTED

先完成一次小练习

准备一段短音频和已有的 SRT / VTT 字幕。这个流程无需注册，也不必先配置 AI。

  1. 安装并打开客户端。从下载区选择设备对应的版本，安装后打开 Clarora。进入「音频管理」。
  2. 创建练习组，导入一段音频。点击「新建组」，确认名称；点击「导入音频」选择 MP3、M4A 或 WAV 等文件。练习组用于整理材料，不会改变原音频内容。
  3. 为这段音频配上字幕。选中音频，导入对应的英文 SRT / VTT。没有字幕时先直接听，稍后按字幕章节生成。
  4. 开始学习。进入「音频学习」，先听一遍，再点击听不懂的句子或单词定位播放。按需要降低倍速，开启「跟随」让字幕随播放位置移动。
  5. 留下一句，明天再听。开启「截取片段」，选出一句、调整 A/B 边界，保存为闪卡。在「闪卡复习」中再次听这段内容。

完成后：你会得到一个练习组、一段带字幕的音频和一张可复习的片段卡。之后再按需要添加 AI、写作或书库。

02 / INSTALL

选择版本并安装

先按设备选择版本
设备选择与打开方式
macOS选择桌面主版本，并按 Mac 的芯片选择兼容的安装包，当前支持范围以下载卡片为准。打开 DMG，将 Clarora 拖入「应用程序」，以后从该位置启动。
Windows选择桌面主版本。安装器按提示安装；若下载的是便携 ZIP，先完整解压，再运行文件夹中的客户端程序，保留同目录运行库和 tools 文件夹。
Android RN使用下载页独立标注的 RN 版本。允许当前下载来源安装应用后打开 APK；不能使用桌面安装包。本手册中的桌面专属操作不一定提供。
iOS RN以下载页实际开放的 TestFlight / App Store 渠道为准。待发布状态不代表已有可直接安装的 IPA。
  1. 以下载页的发布状态为准。显示「待发布」时，查看构建说明或等待渠道开放；不要用其他平台或 RN 的包替代桌面主版本。
  2. 升级前先导出资料备份。退出正在运行的 Clarora，再替换应用或安装新版。检查 Dock、任务栏和快捷方式是否仍指向旧安装位置。
  3. 只运行自己确认来源的下载。未签名构建可能触发系统提示。macOS 可在系统「隐私与安全性」中查看拦截原因；Windows 先核对下载来源和文件完整性，再按系统提示处理。

桌面主版本与 RN 的本机资料目录独立，不会因为安装新版自动双向共享。迁移请使用备份／导入流程。需要从源码构建时，查看桌面说明 ↗或RN 平台说明 ↗。

03 / SET UP AI

分清本地模型与远端 AI

已有资料的阅读、播放和复习可以离线使用。字幕转写可以选本地模型；聊天、中文翻译、写作批改和图片识字会调用你配置的模型服务。

配置聊天、翻译和批改

  1. 打开「设置 → AI 服务」。填写服务商提供的 Base URL、模型 ID 和 API Key。地址格式例如 https://api.example.com/v1，这是格式示例，需要替换为你的服务地址。
  2. 保存，再做一个短请求。点击「保存 AI 与学习设置」，打开「学习助手」提出一个简短问题。能收到完整回答后，再尝试长文批改或整组翻译。
  3. 按任务选择合适能力。图片识字需要视觉能力，可单独填写视觉模型。远端转写需要服务同时支持音频转写接口；只支持聊天的模型不能直接当作转写模型。

选用本地字幕模型

  1. 先下载，再选用。在「本地语音识别模型 · ASR」里下载模型。纯英文可先从较小的 Whisper .en 模型尝试；SenseVoice 面向多语言，实际效果取决于音频和模型。
  2. 切换本机转写并保存。将转写引擎设为 local，选用已下载模型，再点击保存。仅下载文件或点击选用而不保存，不代表配置已生效。
  3. 用短音频验证。生成一小段字幕，确认文字和时间轴。完整分发包会包含相应辅助程序；自行构建缺少 FFmpeg 或推理运行库时，可在「运行环境」查看具体缺项。

网络与密钥：选择本地转写时，转写本身不上传音频；远端转写、翻译和 AI 问答会发送相应材料。较新桌面构建的密钥默认保存在本机数据库，可在「密钥存储」开启系统凭证库保护；不同版本与 RN 的方式可能不同。应用导出的资料备份不包含这些密钥，换机后需单独配置。

04 / AUDIO LIBRARY

把音频整理成练习组

  1. 先选组，再导入。在「音频管理」新建或选择练习组。可按课程、日期、考试或主题分类，避免把所有材料放在同一组。
  2. 导入并核对名称。点击「导入音频」选择文件，导入后在当前组找到它。可用搜索、字幕状态筛选和多选整理材料；学习前确认选中的是正确音频。
  3. 添加对应字幕。为所选音频导入字幕文件，或进入字幕生成。导入后试听开头与结尾，确认字幕属于同一份音频。
  4. 开始或继续精听。从详情进入学习，调整倍速和循环，点击字幕定位。切回音频管理只负责整理资料；真正的学习操作在「音频学习」。

新版功能 更快地导入和命名

新建组会预填日期名称，音频名可双击原位编辑。主窗口右上角「悬浮窗」可打开或关闭快速导入窗口；它显示当前所选组，点击导入按钮执行你保存的命令，导入完成后可直接命名音频。

命令导入需先在设置中保存自己的命令。命令每行输出一个本机音频文件的完整路径，点击导入时才执行，结果归入点击时选中的组。桌面主版本与 RN 的平台支持不同，入口不存在时请看对应版本说明。

需要把文本变成练习材料时，使用「文字转音频」，先安装并选用 Kokoro 模型，再填写文本、生成并保存到所选组。首次模型下载需要联网；本机合成不等于已经生成字幕，仍可另行配字幕。

05 / SUBTITLES

先得到英文，再添加中文

  1. 已有字幕就直接导入。选择对应音频，导入 SRT / VTT；TXT 可按行估算时间轴，精听时优先使用真实带时间戳的字幕。
  2. 没有字幕时生成英文。保存好转写设置，在音频学习工具栏或音频管理中点击「生成字幕」。等待处理结束，再检查实际内容。
  3. 再翻译成中文。点击「翻译成中文」，使用聊天 AI 生成双语字幕。它保留英文和时间轴，不需要重新识别音频；翻译需要可用的 AI 服务。
  4. 检查时间边界。听一句开头和结尾，确认没有提前停止或混入下一句。生成结果可能识别错误；旧字幕时间轴不准时，可先保留原文件，再重新生成当前材料并翻译。
一个最小 SRT 示例
1
00:00:00,000 --> 00:00:03,000
I learn a little every day.

2
00:00:03,000 --> 00:00:06,000
Small steps make a difference.

把示例保存为 UTF-8 编码的 lesson.srt 即可用于熟悉导入流程。示例时间不对应你的真实录音，需要用实际材料的字幕替换。

新版功能 整组音频处理

在「音频管理」选择目标组，点击整组生成英文或整组翻译中文。程序按组处理，跳过已有结果；部分中文缺失时按需补齐。发生错误会继续处理其他音频，并汇总失败项。取消后已经完成的结果会保留。

这与视频的「全部P翻译中文」规则不同：视频只要某个 P 任一句已有中文，就跳过整个 P，避免覆盖已有翻译。

06 / VIDEO STUDY

一句一句听懂视频

  1. 导入本地视频或 B 站来源。进入「视频学习」，从「更多」中打开本地视频或 bilibili 导入，填写 BV 号、av 号或完整链接。下载受网络及来源可用性影响。
  2. 选择要学习的 P。多 P 视频在标题栏 P 数或右侧「选集」里切换，先准备对应媒体。不同 P 的字幕和时间轴分别保存，不要把同一篇文稿套到另一个 P。
  3. 准备英文与中文。在右侧「字幕」导入英文字幕，或生成当前 P 的字幕；需要中文时再点「英文生成中文」。可先用「全部P生成字幕」准备英文。
  4. 开启逐句重复。某句下方点「无限重复」或「重复三次」，也可从控制栏「本句重复」选择。三次模式会在本句播放三遍后自动进入下一条有效字幕，最后一句完成后暂停。
  5. 结合文稿与提问。「英文文稿」查看整篇纯英文转录；需要理解句意时，用当前句、某条字幕或整段字幕作为 AI 引用，再输入具体问题。

新版功能 批量翻译与返回续播

「全部P翻译中文」读取已有英文缓存，任一句已有中文就跳过整个 P；缺英文的 P 会列出失败原因，不会为了翻译自动下载和重新转写。先生成英文，再重试未完成部分。

切到其他栏目时保存并暂停视频，返回后停在离开的位置，点击播放继续。手动跳转或离开视频模块会结束旧的逐句重复模式。

07 / REVIEW

把值得记住的内容留下

  1. 导入自己的词卡。在「闪卡复习」的学习选项中选择文本或 Anki 导入。先用几张卡确认格式，再导入大量内容；RN 移动端的导入能力请查看平台说明。
  2. 选择复习方式和类型。计划复习优先安排到期卡，并受每日新卡额度限制；自主复习按你选择的内容练习。可按单词、句子、AI 问答或片段筛选。
  3. 先回忆，再评分。查看答案后按真实掌握程度选择评分，它会影响下一次复习时间。音频片段卡可先听再揭示文字。
  4. 从精听中制作片段。在音频学习开启「截取片段」，点击单词确定范围，Shift 点击扩展，拖动波形上的左右边界试听；保存为闪卡。视频使用 A/B 范围保存片段。
文本词卡格式示例
clear - 清晰的
focus - 专注
review - 复习

一行一张词卡；也可用 Tab 等支持的分隔符。导入目录的替换行为与普通追加导入不同，使用前确认界面的范围说明并保留备份。

新版功能 已收藏的片段会在字幕中以下划线标出。左键仍用于定位或选段，右键已收藏部分打开取消收藏复习入口；取消会移出对应闪卡复习，保留媒体和字幕。AI 重点下划线与片段收藏是不同标记。

08 / WRITING

保存题目，写下自己的回答

  1. 新建一篇写作。进入「写作练习」，新建草稿。标题可选，建议写上考试、主题或日期，方便后续查找。
  2. 把要求写完整。在「写作题目」编辑器里放入题目、任务要求或评分标准；在「我的作答」里输入正文。支持中英文和多行文本。
  3. 保存并提交批改。输入会自动保存，也可点击「保存写作」。确认题目和作答后点击「AI 批改」，本次题目与作答会一起发送至设置中的模型服务。
  4. 结合反馈修改。检查切题程度、结构、语法和用词建议；修改自己的原稿，再按需要发起下一次批改。批改记录保存本次提交的快照，不会替你覆盖原稿。

建议这样提要求：在题目中写清字数、体裁和希望重点检查的方面。未提供评分标准时，模型反馈不应被当成正式考试评分。

09 / READING

阅读 PDF 与电子书

  1. 导入书籍。进入「文档阅读」，选择 PDF、EPUB 或 TXT。桌面主版本支持这三种格式；RN 的文档阅读以对应版本的 PDF 能力为准。
  2. 用目录和页码定位。打开书库中的材料，通过目录、上一页／下一页或页码导航阅读；PDF 可调整缩放，电子书按章节和内容分页展示。
  3. 围绕当前材料提问。打开学习助手，先确认引用的是正确书籍或页面，再问词义、段落结构或内容理解。扫描型 PDF 的页面图像识字需要视觉模型和网络服务。
  4. 继续阅读并备份。客户端保存阅读进度；换机前导出含附件的资料备份，再在目标设备导入。只复制数据库而不复制书籍文件，不能保证重新打开材料。

EPUB 与 PDF 的分页方式不同，页码可能不对应纸质书。带加密保护或其他格式的书籍不能保证直接打开；遇到格式错误，先确认文件完整且属于支持的类型。

10 / PRACTICE

跟读一句，也读懂一页

口语跟读

  1. 准备参考句。在口语跟读中填写参考文本，或从当前学习材料开始跟读。先听懂句意，再录下自己的朗读。
  2. 允许麦克风并完成录音。点击录音，按系统提示授予权限，读完后停止；无音频时先检查系统输入设备及应用麦克风权限。
  3. 转写并查看对照。使用保存的转写设置识别录音，再查看文本对齐与反馈。该分数主要反映转写文本与参考句的匹配，不能等同于完整的发音或音素评估。

拍照识字

进入「拍照识字」，选择需要识别的图片；支持拍照的设备可从相应入口拍摄。先配置可用的视觉模型，识别结果可以复制或交给学习助手继续提问。远端视觉识别会发送图片，不属于本地字幕模型的离线能力。

11 / FOCUS

让一次练习有开始和结束

  1. 选择时长并开始。使用全局「专注时间」条的「专注时长」选项，或进入「冥想专注」。同一轮计时在模块间共用。
  2. 按需要暂停或继续。切换学习栏目不必重新开一轮；临时离开可暂停。重置会改变当前轮次，不是普通继续。
  3. 注意阶段变化。专注完成后进入休息，再按当前设置继续。若没有提示音，检查应用音量、系统输出设备和版本是否包含相应提示音实现。

新版功能 新构建会保存运行中的截止时间或暂停剩余时间，退出后重开按实际经过时间恢复。关闭期间已经到期时只结算上一轮，并停在下一阶段等待继续，不自动累计离线多轮。早期没有保存的计时无法事后找回。

12 / KEEP YOUR LIBRARY

备份资料，再安心换设备

先做一份本机 ZIP 备份

  1. 打开设置中的备份入口。选择导出本机资料，保存 ZIP 到你方便管理的位置。完整备份包含学习记录和对应附件，不只是一个数据库文件。
  2. 在目标设备导入。打开 Clarora 的导入／恢复入口，选择备份文件，等待合并结束。先核对词卡、音频、书籍和阅读位置，再删除旧设备上的资料。
  3. 从 RN 迁移时选对入口。桌面主版本可导入 RN 数据库快照；两版资料目录独立。涉及音频或书籍时需保证原附件可读，迁移前保留两端备份。

使用自己的对象存储换机

  1. 保存存储配置。填写 S3 兼容存储或阿里云 OSS 的 Endpoint、Bucket、区域／前缀和所需密钥。具体字段以所选服务与客户端表单为准。
  2. 先上传一个备份版本。点击云备份入口，等待上传完成。只保存存储配置不会自动上传或自动同步资料。
  3. 另一端读取并合并。配置相同存储位置和前缀，读取版本列表，选择需要的版本合并到本机；不要把“没有读取到版本”当成可以删除旧资料。

这是手动版本备份与合并。不是自动实时双向同步，也不会自动传播删除。本机已有内容优先，复习进度按相应较晚评分合并。应用备份不包含 API / 存储密钥，目标设备要重新配置；HTTPS 传输也不等于端到端加密。

新版功能 新构建的云备份对 B 站原片保存来源链接、字幕及学习记录，恢复后按需重新下载；自己导入的本地视频仍按附件备份。本机 ZIP 会保留可用的视频原文件。来源下架或失效时，链接不保证仍可下载。

13 / TROUBLESHOOTING

遇到问题，从这里排查

更新后界面还是旧的，或找不到教程中的按钮

先退出所有旧实例，再从刚安装的位置打开 Clarora，确认 Dock／任务栏没有仍固定旧包。RN 和桌面主版本的界面不同；「新版功能」也不一定在早期 v0.2.2 中。回到下载区核对版本和发行说明。普通安装包更新后无需自己重新编译。

字幕重复播放时，开头或结尾被截断

逐句重复使用字幕已有的起止时间。先试听原片的对应位置，保留旧字幕后对当前音频或 P 重新生成，再按需要翻译中文。A/B 工具可用于微调本次片段范围，但不等于编辑整份字幕时间轴；不要把反复重播当作已经校准字幕。

英文字幕能生成，中文翻译却失败

英文可能走本地转写，中文翻译则使用聊天服务。检查是否已保存 Base URL、模型 ID 和 API Key，先用学习助手完成一次短问答，再重试翻译。不要只重新下载字幕模型。

AI 返回 401、404 或 429

401 通常与密钥或授权有关；404 检查地址、模型 ID 和接口是否支持；429 查看服务商的限流或额度提示。以实际错误内容为准，避免反复提交长音频。Base URL 不是服务商控制台的网页地址。

模型已经下载，仍提示无法转写

确认模型已选用并保存、转写引擎是 local，且模型文件完整。打开「运行环境」检查 FFmpeg 和推理辅助程序；下载模型不会自动安装自行构建所缺的原生运行库。先使用短音频复验。

音频、视频或计时没有声音

依次检查客户端是否暂停／静音、音量、系统输出设备和耳机连接。换一个已知能正常播放的文件再试。录音问题还需检查麦克风权限和输入设备；计时提示音与学习媒体属于不同播放路径。

B 站视频导入失败或某个 P 无法播放

检查链接是否正确、当前网络能否访问来源，以及该 P 是否仍可观看。已恢复的来源记录不表示视频文件已经下载；选择对应 P 按提示准备媒体。查看客户端任务错误，不要用另一 P 的字幕掩盖缺失媒体。

换设备后看不到资料或云端版本

确认旧设备已完成一次备份，新设备使用相同 Endpoint、Bucket 和前缀，读取版本后执行合并。两版客户端并不共用同一资料目录。保留旧库和备份，先核对附件路径与读取权限；仅配置云存储不会自动下载资料。

哪些操作会联网，资料会发到哪里

本地阅读、复习、播放以及配置正确的本地转写／语音合成可离线运行。模型下载、B 站导入和云备份需要联网；远端转写会发送音频，翻译／问答／写作批改会发送引用文本，图片识字会发送图片至你选择的服务。官网教程不读取或上传这些资料。

仍有问题时，可在GitHub Issues ↗说明客户端版本、系统、操作步骤和错误信息。截图或日志中请去掉密钥与不希望公开的学习资料。
