YOUR DAILY WORKFLOW

先从四个核心练习开始。

音频、视频、写作、口语，各自一条最短路径。
先完成一个，再按手册深入。

  1. 建组并导入：在「音频管理」新建练习组，导入 MP3 / M4A / WAV，双击音频名可直接改名。
  2. 让字幕对上：导入对应的 SRT / VTT，或按设置生成英文；先试听开头和结尾，确认字幕属于这份音频。
  3. 换粒度精听：整段听大意，难句用「单句循环」，通篇跟听用「每句三遍」；需要时开 A–B 只练一个片段。
  4. 留下再复习：截取一句保存为闪卡，第二天在「闪卡复习」先听后看；想找同类句型就去「句型搜索」。

音频精听的完整流程 ↗ · 片段闪卡与复习 ↗

  1. 先准备这一集：导入本地视频或 bilibili 链接，多 P 视频在「选集」里选对 P，不要跨 P 套用同一份字幕。
  2. 先英文后中文：导入或生成当前 P 的字幕，再点「翻译中文」；整季学习可用「全部P」批量处理。
  3. 按句精听：「单句循环」反复听一句，「每句三遍」自动推进；← / → 切句，A–B 练一个范围。
  4. 带着文稿输出：用「英文文稿」通读，复制单句、双语或英文全文，或引用字幕向学习助手提问。

视频逐句精听步骤 ↗ · 字幕生成与批量规则 ↗

  1. 建组再新建：在「写作练习」按考试或话题分组，给每篇写作一个能找回的标题，需要时加标签。
  2. 题目和作答分开：完整粘贴题目与评分标准，带格式的内容会保留样式；写下初稿并设置目标词数。
  3. 选一种批改：初稿用「综合批改」看切题与结构，定稿前用「逐处修改」看具体改法。
  4. 改出下一版：对照历史意见修改原稿，每次提交都保留快照；有疑问就点「追问 AI」带着上下文继续问。

写作批改的完整闭环 ↗ · 配置批改用的聊天模型 ↗

  1. 建口语题库：在「口语练习」新建分组，每道题以音频为来源；可转写题目并生成中文。
  2. 准备自己的答案：写作答草稿、设置目标词数，需要时用本机 Kokoro 生成读音先听一遍。
  3. 录下来对照：播放参考后录音，转写识别，查看漏读、读错、多读、完整度和语速。
  4. 只改一个重点：重录最影响理解的一句；整组题可一起批改，检查前后答案是否重复。

安装与故障处理

  • macOS 打开被拦：当前发行未做 Apple 公证。首次打开若被 Gatekeeper 拦截，在「访达 → 应用程序」中右键 Clarora 选「打开」，或在终端执行 xattr -dr com.apple.quarantine /Applications/Clarora.app。运行时库已内置，无需 Homebrew。
  • Windows 安装：运行安装器即可按用户安装；便携 ZIP 解压后运行 Clarora，无需开发者模式或侧载脚本。运行库随包提供，未签名安装包可能触发 SmartScreen 提示。
  • 端侧转写不可用：桌面包内置转写组件，语音模型在设置中另行下载；可在「运行环境」查看组件状态。录音不可用时检查麦克风权限。
  • 升级与资料：本机学习资料与应用安装目录分开保存；升级或切换 RN 版本前，可先在应用内导出备份。

平台差异与更新记录

  • macOS / Windows：默认桌面下载为 Clarora 主版本，两平台使用相同的本机播放器与字幕学习界面。
  • RN 版本：历史桌面发行保留在 Releases 中，标题带 RN，便于与主版本区分。
  • Android / iOS RN：移动端保留独立版本与分发入口；平台能力和安装渠道以对应 RN 发行说明为准。
  • 更新记录：RN v0.1.0（2026-09-18）首个公开版本——闪卡复习、音频学习、端侧字幕、口语跟读、PDF 阅读、自有存储备份、Anki 导入（桌面端）。 后续版本见 Releases 页面 ↗。

从源码构建

需要 Rust 1.93.1、Xcode Command Line Tools 和 Homebrew。克隆源码后，在仓库根目录构建桌面主版本： 

brew install mpv ffmpeg yt-dlp
sh clarora-gpui/scripts/package-macos.sh
python3 clarora-gpui/scripts/install-pdfium.py clarora-gpui/target/Clarora.app/Contents/MacOS
codesign --force --deep --sign - clarora-gpui/target/Clarora.app
open clarora-gpui/target/Clarora.app

各平台能力有所差异，源码可构建不等于完成设备验收。阅读详细平台说明 ↗

A FEW THINGS TO KNOW

开始之前，
你可能想知道。

保持简单，也把事情说清楚。

需要注册或开通会员吗？+

不需要 Clarora 账号，本地学习功能可以直接使用。AI 功能需要配置你自己的模型服务，相关费用由所选服务提供方决定。

可以离线学习吗？+

已经导入的资料可以本地学习。下载好模型并选用后，本地字幕转写和语音合成可离线运行；远端 AI、中文翻译、模型下载及云备份需要网络。

不同设备之间怎么同步？+

在各设备配置相同的 S3 兼容存储或阿里云 OSS。一端手动备份，另一端读取版本并合并。目前不是自动实时同步，也不会自动传播删除；本机已有内容优先，复习进度采用较晚的评分。

我的资料和密钥存在哪里？+

学习资料保存在设备本地，备份时上传到你配置的对象存储。AI 请求会把相关内容发送至你选择的模型服务。密钥的存储方式取决于客户端与版本：较新桌面主版本默认使用本机数据库，可选开启系统凭证库保护；RN 参见平台说明。应用导出的资料备份不包含密钥；HTTPS 传输不等于端到端加密。

四个平台的功能完全相同吗？+

桌面主版本与移动端 RN 的模块、导入方式和原生能力有所不同。先选择设备对应的版本，再按使用手册的适用说明操作；较新桌面功能不一定出现在旧包或移动端中。

有网页版学习应用吗？+

目前专注于 macOS、Windows、Android 和 iOS 客户端。本网站用于介绍与使用指引，上方交互是功能示意，不会保存你的学习资料。
