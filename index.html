YOUR DAILY WORKFLOW

五个场景，学会日常使用。

从导入内容到离线字幕、跟读评分，
每一步都在你的设备上完成。

  1. 导入词卡：首页闪卡 → 「学习选项」导入文本词卡，每行一个单词，支持 Tab、逗号、 - 等分隔符，# 开头的行会被忽略。
  2. 整目录换卡组：macOS 可用「导入目录」，以目录为唯一来源整体替换卡组；删掉已学会的单词后重新导入，App 内同步消失。
  3. 导入 Anki 卡组：桌面端学习选项 → 「Anki 卡组」，选择 .apkg / .colpkg 文件，笔记清洗为纯文本卡片并合并进词库；填空题自动还原答案。移动端无需导入，桌面导入的卡片经「同步与备份」下发。
  4. 导入音频：音频管理 → 添加音频，使用系统文件选择器选择 MP3/M4A/WAV 等；macOS 还支持目录批量导入和命令导入。
  5. 导入字幕：字幕支持 SRT / VTT / TXT（TXT 按行估算时间轴），也可直接用「AI 生成字幕」。
  1. 下载端侧模型：设置 → 字幕转写引擎 → 选择模型并下载。SenseVoice 支持中英日韩粤（自动检测语言），Whisper .en 模型适合纯英文；转写完全离线，音频不上传。
  2. 生成字幕：听力页或音频管理点「AI 生成字幕」，稍等片刻即可得到带时间轴的字幕。
  3. 翻译成中文：点「翻译」生成中英双语字幕——翻译使用「AI 服务」里你配置的聊天模型，逐句对齐原时间轴。
  4. 收藏片段：截取喜欢的句子收藏为听力闪卡，复习时自动播放该段音频。
  1. 配置 AI 服务：设置 → AI 服务，填写 OpenAI 兼容的 Base URL、API Key 和聊天模型；也可以指向本机运行的开源模型服务。
  2. 随选随问：点右下角「✦ AI 助手」，当前学习内容自动成为引用；选中字幕右键提问（macOS），回答支持流式输出。
  3. 存为卡片：把有用的回答「存为 AI 问答卡」，正面是问题与原文，背面是完整回答，进入 SM-2 复习队列。
  4. AI 标重点：听力页「标重点」让 AI 圈出重点词汇，字幕中以高亮标出，点击任意一条跳到对应句子播放。
  1. 录一句跟读：听力页点「🎤 跟读」，朗读当前句子，播放自动暂停，录完自动转写。
  2. 对齐评分：基于识别文本对齐给出完整度 / 准确度 / 语速，并列出漏读、读错与多读的词（识别由端侧引擎或你的转写 API 完成）。
  3. 教练点评：AI 根据原文与识别结果给出简短练习建议，只评价文本，不推断发音音质。
  4. 追踪进步：跟读记录保存在本机并随资料备份，统计页可看最近 20 次的准确度趋势。
  1. 准备存储：设置 → 同步与备份，配置自己的 S3 兼容存储或阿里云 OSS（Bucket + 前缀 + 专用密钥）。不需要 Clarora 账号或服务器。
  2. 备份本机：点「备份本机资料」，词卡、音频附件、字幕、收藏、复习计划与统计打包为完整版本上传。
  3. 换机合并：新设备配置相同存储位置，读取版本列表后「合并到本机」；复习进度取较晚评分，本机已有内容优先。
  4. 边界须知：手动版本备份，不自动传播删除；凭证只存本机应用数据库；云端传输走 HTTPS，暂无端到端加密。

各平台功能有所差异（如命令导入仅 macOS 提供），细节见 平台说明 ↗。

A FEW THINGS TO KNOW

开始之前，
你可能想知道。

保持简单，也把事情说清楚。

需要注册或开通会员吗？+

不需要 Clarora 账号，本地学习功能可以直接使用。AI 功能需要配置你自己的模型服务，相关费用由所选服务提供方决定。

可以离线学习吗？+

已经导入的词卡、音频和字幕可用于本地学习。AI 功能需要连接你配置的服务；云存储备份也需要联网。

不同设备之间怎么同步？+

在各设备配置相同的 S3 兼容存储或阿里云 OSS。一端手动备份，另一端读取版本并合并。目前不是自动实时同步，也不会自动传播删除；本机已有内容优先，复习进度采用较晚的评分。

我的资料和密钥存在哪里？+

学习资料保存在设备本地，备份时上传到你配置的对象存储。AI 请求会把相关内容发送至你选择的模型服务。凭证在 macOS / Windows 保存在系统凭证保险库，移动端暂存本机应用数据库，均不进入云端备份；云端备份使用 HTTPS，尚无端到端加密。

四个平台的功能完全相同吗？+

共享学习页面和数据模型，但原生能力有所差异。例如命令导入仅在 macOS 提供，iOS 的音频学习库通过备份合并获得。具体能力和构建条件请查看平台说明。

有网页版学习应用吗？+

目前专注于 macOS、Windows、Android 和 iOS 客户端。本网站用于介绍与使用指引，上方交互是功能示意，不会保存你的学习资料。
